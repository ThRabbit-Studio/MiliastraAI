# 模型路线实测记录 — 为什么"生成式回复"在这条路上走不通

日期：2026-10-02
相关脚本：`model/train_bigram.py`、`model/sample.py`、`verify/feasibility_minimind.py`、
`verify/feasibility_train.py`

---

## 一、先说平台硬约束（不是难度问题）

| 约束 | 数值 | 来源 |
|---|---|---|
| 编辑器关卡上限 | **20MB** | 用户提供 |
| 客户端 Lua 解算速度 | 约 **1.5e7 ~ 4e7 次乘加/秒** | `verify/feasibility_train.py` 实测本机 lupa |
| 帧预算 | 16.6ms（60fps） | — |
| 本机可用训练框架 | **只有 numpy**（PyTorch 装不上：PyPI TLS 被拦） | 环境实测 |

实测矩阵吞吐：numpy 512×512 约 **73 GFLOP/s**，768×768 约 **166 GFLOP/s**。
所以**训练不是瓶颈**，1M 参数在这台机器上 0.6~2.5 小时能训完。

## 二、MiniMind2 为什么不能直接用

| 模型 | 参数 | int8 权重 | 装进 20MB? | 每字耗时 | 20 字回复 |
|---|---|---|---|---|---|
| MiniMind2-Small | 26M | 33.1M | **否** | 2.25~5.99s | **45~120 秒** |
| MiniMind2 base | 104M | 132M | 否 | 2.95~7.88s | 59~158 秒 |
| 自训 4M | 4M | 5.1M | 是 | 0.29~0.77s | 6~15 秒 |
| 意图分类器 0.5M | 0.5M | 0.6M | 是 | 0.02~0.05s | 0.4~1 秒 |

**两道墙同时撞上**：体积装不下（26M 参数 > 20MB 上限），速度不可接受（每字数秒）。
体积不是主要瓶颈（16MB 能装约 12M 参数），**速度才是**。

## 三、实际训了一个 1M 级模型，结果如下

### 语料
本机没有可用的中文语料来源（HF 主站被拦），所以自己造：
`build/make_corpus.py` 用「问法模板 × 答句骨架 × 槽位词表」生成，
得到 **6954 轮 / 265,282 字**（约 0.8MB）。其中真实语料只有 381 轮。
**必须写明：这份语料绝大多数是模板生成的，只能让模型学会"说话方式和常用字"，
不是知识语料。**

### 模型
一阶字符模型（前一个字 -> 下一个字），闭式解（条件频率 + 拉普拉斯平滑）。
- 词表 3034 token（语料用字 + 字库常用字）
- 参数矩阵 3034×3034 = **9,205,156**，非零转移仅 3,294 条（0.04% 稠密）
- 剪枝到每行前 24 个 token 后：**62,835 字节**
- 训练集 loss 1.66 / ppl 5.2，训练耗时 **0.8 秒**

### 生成结果（这就是判定依据）
```
可以…  -> 可以再核一下这件做起来再谈优化。你介绍一部分析要有，先
我…    -> 我要调整。我一下了。我已经标出来放在听。你接着说
这个…  -> 这个我想解有三处可以再找方法，你想法写下了。你觉。这些东
不…    -> 不上，我答不要调整。这个我已经标准说。我不迟。你
```

**结论：词能认，句子不通。** 这不是实现 bug，是一阶模型的固有上限——
它只记相邻两字的关系，没有任何长程上下文。

### 顺带发现的一个坑
词表里如果混进字库自动扩充层的冷僻字（麥、鶯、鷹、麼），
模型对它们学成均匀分布，采样时会随机吐出来，直接变乱码：
`鹼黑这个我先看有顺序` / `麥黄不确就有三处理解决什么程度`。
已修：词表只取「语料用字 + 字库小学年级字」。

## 四、结论与建议

**不要在关卡里用生成式回复。** 依据：
1. 一阶模型输出实测不通顺（上面四行就是证据）；
2. 真 Transformer 要长程上下文才能好转，但 1M 参数预算下注意力占比太低，
   且训练要数小时，收益不确定；
3. 更关键的是：**玩家打出的问题五花八门，生成式模型没有任何机制保证"答得对"**，
   它只会说像中文的话。

**建议改为「小神经网做匹配 + 扩充答案池 + 必回应」**：
- 一个 0.5M 参数的小网络负责**理解意图**（把玩家输入编码成向量，与答案池条目比相似度），
  这是真模型在算，推理 0.4~1 秒，可 int8 量化，体积 0.6MB；
- 答案池从 90 条扩到 500~1000 条**人工可控**的答句，质量有保证；
- 匹配不到时走「必回应」机制（多轮追问 / 引导式反问），保证任何输入都有回应。

这样既满足"接入真正的 AI 模型"，又不会让玩家看到乱码。
