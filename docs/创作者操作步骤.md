# 创作者操作步骤 — 千星奇域离线对话（拼音首字母输入）

> 本文件是给**创作者**的操作说明。代码已经写好并离线验证通过，你只需要完成下面的编辑器配置，并把几个索引填给我。

---

## 第一步：建立客户端脚本，把代码贴进去

1. 打开「千星沙箱」窗口，点击右上角「窗口」→「客户端脚本资源管理器」
2. 双击「未分类页签」或你自己建的文件夹
3. 右键 →「新建客户端脚本」
4. 单击上方路径确保全选，`Ctrl + C` 复制。这是**脚本路径**
5. 下方「文件名」填 `main`（这样会生成 `main.lua`）。复制这个名称，这是**脚本名称**
6. 点击「保存」
7. 打开生成出来的 `main.lua`，把交付的 `out/main.lua` 的内容**整份覆盖**进去，保存

> ⚠ 覆盖后不要再动文件里的 `-- [[SPEECH_BANK_BEGIN]] ... [[SPEECH_BANK_END]]` 之间的内容，
> 那一段是构建脚本生成的语料数据，手改会在下次构建时被覆盖。

---

## 第二步：把脚本挂到界面布局上

1. 回到「原神」窗口，前往「界面控件组管理」
2. 左上角切换需要挂载的「界面布局」
3. 点击左下角「添加界面控件」
4. 展开「预制模板」，创建「客户端控件容器」
5. 选中刚创建的容器，在右侧边栏「画布设置」中点击「前往编辑」
6. 确认当前选中的是「容器节点」，点击右上角「复制」。这是**容器节点索引**
7. 在右侧切换「脚本」页签，点击「添加脚本」，选择第一步创建的脚本

---

## 第三步：创建一个图片控件模板

本交付的画面**全部用基础图元（方形）拼出来**，不使用编辑器图片库。

1. 前往「界面控件组库」
2. 左上角切换为「客户端控件模板」
3. 点击左下角「添加客户端控件」，创建一个**图片控件**
4. 复制它的索引。这是**图片控件模板索引**
5. 图片内容、颜色、尺寸、位置、锚点都**不需要**在模板里设置，代码会在运行时绑定

---

## 第四步：把索引填进代码

打开 `main.lua`，在最上面的配置区填一个数：

```lua
local CFG = {
    -- ★ 必须由创作者填：图片控件模板索引（基础图元方形，tintable、可拉伸）
    IMAGE_PREFAB_INDEX = 0,     -- ← 填第三步拿到的图片控件模板索引
    ...
}
```

**没填之前不会创建任何控件**，日志里只会看到一条提示：

```
GAME FAULT BEGIN E_SPEECH_01
stage=CONFIG
reason=图片控件模板索引未填写：IMAGE_PREFAB_INDEX 需要填入创作者提供的索引
GAME FAULT END E_SPEECH_01
```

填好之后进关卡，会看到一次启动汇总：

```
[SPEECH] INIT prefab=<你填的> bank=126 persona=奇匠·阿澜
[SPEECH] UI 就绪 canvas=1920x1080 scale=1.000 控件=22
[SPEECH] 已注册按键监听 44 个
```

## 怎么玩（也可以直接告诉试玩的人）

打问句的**拼音首字母**。`zh/ch/sh` 就是连按两个字母。

| 操作 | 按键 |
|---|---|
| 打拼音首字母 | `A`–`Z` |
| 选中第 N 个候选问法 | 数字键 `1`–`0` |
| 让程序自己猜 | `F5` |
| 删除一个字符 | `Backspace` |

**例子**：想问「你是谁」→ 首字母 `N S H S H` → 依次按 `N` `S` `H` `S` `H` → 按 `1` 选中，或直接按 `F5`。

界面上有一行按键图例，按错也没关系，不会崩。

## 想改哪里

都在文件最上面的 `CFG` 里：

| 想改什么 | 改哪里 |
|---|---|
| 发送键 | `SEND_KEY = "F5"`（必须是奇匠按键，即文档 §26 里枚举 1-43 的那些） |
| 候选显示个数 | `MAX_CAND`（默认 7） |
| 逐字显示快慢 | `CHAR_INTERVAL`（默认 0.045 秒/字，改小更快） |
| 配色 | `COLOR_PANEL` / `COLOR_TEXT` 等 |
| 对话内容 | 改 `data/questions.json`，然后跑 `python build/build_speech.py` |

⚠ **不要改 `KEY_INDEX` 表**（物理键→按键编号）。那张表是照文档 §26(1) 的枚举序号逐行对齐的，而文档的"默认物理键"文字栏与序号错位一行、极易看错。要改请先跑 `python verify/t_harness.py`。

## 首次进关卡请重点帮我看这几项

| 项 | 现象 | 怎么反馈 |
|---|---|---|
| **按键映射** | 按字母没反应，或按了别的键才响应 | 记下"按了什么键、期望什么、实际什么" |
| 面板是否显示 | 出现问号、纯色块、或整个不显示 | 一张截图 + 启动汇总块 |
| 逐字显示 | 文字是否一个字一个字冒出来 | 同上 |
| 待机是否吃性能 | 显示完之后帧率是否恢复 | 同上 |

出问题时，请把日志里 `GAME FAULT BEGIN/END` 之间的**完整连续块**，以及所有 `[SPEECH]` 开头的行发我，不要只发一行。
